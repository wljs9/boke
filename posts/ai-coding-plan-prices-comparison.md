# 国内各 AI 产品的 Coding Plan 价格对比（2026 年版）

> 数据截止：2026年8月20日 | 作者：施志亮

---

## 一、引言

如果你是一个 2026 年的开发者，打开 VS Code 或 JetBrains IDE，你很可能会面对一个灵魂拷问：**AI Coding 助手是标配了，但到底该为谁的 Coding Plan 掏钱？**

这个问题的答案在 2025 年还算简单——Cursor + GitHub Copilot 几乎统治了英文开发圈。但进入 2026 年，国内 AI 厂商的编程能力已经发生了质变：字节跳动的 Doubao-Seed、月之暗面的 K3、智谱的 GLM-5.3、MiniMax 的 M3——每一家都在 Coding 这一垂直场景上投入了重兵。更关键的是，**2026 年 8 月初，零一万物宣布退出个人开发者市场**，彻底转向企业级 AI 解决方案，让本就激烈的定价战局又多了一层变数。

这篇文章不聊模型跑分、不聊营销话术，只做一件事：**把 9 家国内主要 AI 厂商的 Coding Plan 价格拉出来，摊在桌面上对比**。看完你会知道，哪一档的钱花得值，哪一家最擅长在价格上动脑筋。

## 三、逐产品深度分析

### 3.1 字节跳动 Trae：性价比屠夫

Trae 的前身是豆包 MarsCode，2026 年改名后明显加大了定价力度。

**免费版**给 500 积分/月 + 2 个云端任务，涵盖所有功能，对于偶尔使用 AI 辅助的程序员来说已经够用了。但真正亮眼的是 **Lite 套餐**：首月仅 ¥9.9（原价 ¥49），给 2,000 积分/月。这个定价策略明显是"先让你用上手，然后很难离开"——字节太懂用户心理了。

主力 Pro 套餐 ¥59/月，4,000 积分/月，10 个云端任务。再往上是 Pro+ 套餐 ¥219/月（原价 ¥239），12,000 积分/月，同样 10 个云端任务。旗舰 Ultra 跳到 ¥629/月，给了 40,000 积分/月，20 个云端任务。整个定价曲线的斜率很陡：从 Pro 到 Pro+，价格翻了 3.7 倍，积分只翻 3 倍；从 Pro+ 到 Ultra 又翻了近 3 倍，积分翻 3.3 倍。

**为什么重要**：Trae 的定价告诉你，字节的策略不是靠订阅赚钱，而是用低价把开发者锁进豆包生态。Doubao-Seed 模型在代码补全和生成上的表现已经被很多开发者认可，但如果你用 Trae 写的代码大量依赖 Doubao 特有的模式，迁移成本就成了隐形成本。

### 3.2 月之暗面 Kimi Code：贵，但 K3 可能值这个价

Kimi Code 的定价方式和其他家都不一样——**没有免费额度**，最低门槛 ¥39/月（Andante，原价 ¥49）。这在小厂商还在用免费版抢用户的市场里，显得格外自信。

这种自信的来源是 K3 模型。K3 支持 **1M 上下文窗口**，意味着你可以把整个代码仓库扔进去让它理解——这在做大型重构或者跨文件 debug 时，实际体验差距非常明显。从 Moderato（¥79/月）开始就能用 K3，这个定价如果和实际的编码效率提升匹配，那就非常有竞争力。

旗舰 Allegro ¥559/月，和阿里 Qoder 的旗舰版完全同价——这不是巧合，两家都在瞄准"重度编码用户"这个细分市场。

**需要注意**：K3 推出后，Kimi Code 的套餐一度需要预约才能购买。这说明需求端很真实，但也意味着供应端可能还没准备好。

### 3.3 阿里巴巴 Qoder CN：产品矩阵最深

Qoder CN 的前身是通义灵码，2026 年改名后产品线大幅扩展。和其他家只做一个 IDE 插件不同，Qoder 有 **IDE、CLI、QoderWake、Cloud Agents、JetBrains 插件**——产品矩阵是 7 家里最深的。

**体验版**免费给 300 Credits（2 周试用），接入 Qwen3.8-Max 加第三方模型。主力专业版 ¥59/月给 2,000 Credits，和 Trae 的 Pro 同价。还有一个资源包 ¥40/1,000 Credits（1 个月有效期），适合偶尔需要"加餐"的用户。

Token Plan 另有一套定价：Lite ¥39/月 → Standard ¥139/月 → Pro ¥499/月，对应的是纯 API 按量使用场景。

**为什么重要**：如果你既要做个人项目，又要和团队协作，Qoder 的 Cloud Agents 功能（云端的自动化 Agent）比其他家的"纯 IDE 补全"模式多了一个维度。这个产品深度让它在中型团队场景里很难被替代。

### 3.4 智谱 AI GLM Coding Plan：学术派突围

智谱走的是 CodeGeeX + GLM Coding Plan 双线策略：CodeGeeX 提供免费的代码补全/翻译/问答，GLM Coding Plan 做付费的高级编码服务。

主力 Pro ¥149/月（~400 prompts/5h）——这个定价比 ¥59 的主流锚点贵了一倍多。但 GLM-5.3 号称**编程能力提升 50%，达到国内 SOTA 水平**，支持 1M 上下文，API 定价 ¥8/百万 tokens 输入，¥28/百万 tokens 输出。入门 Lite 档 ¥49/月（~80 prompts/5h），适合轻度使用。

**值得关注的点**：智谱是 9 家里唯一把 prompt 频次（Lite "~80 prompts/5h"，Pro "~400 prompts/5h"）而不是积分或 credits 作为额度计量单位的。这种方式的优点是直观——你知道自己每小时能问多少次；缺点是不灵活——一次"帮我改一个变量名"和一次"重构整个模块"消耗的是同一个 prompt 额度。

### 3.5 百度 Comate：大厂的稳健打法

百度的 Comate 定价在 7 家里面最"正常"——免费版注册送 ¥10 额度，专业版 ¥59/月（含 ¥55/月模型额度），旗舰版 ¥199/月。

有意思的是 Comate 还有**千帆 Token Plan**：Mini ¥4.9/月给 1,000 万 tokens，这是全市场最低的 token 单价之一。而且企业版从 ¥149/月（轻享）一路拉到 ¥989/月（高级），说明百度在 B 端市场有自己的一套打法。

**为什么重要**：Comate 的定价曲线是 7 家里最平滑的——从 ¥0 → ¥59 → ¥199，没有中间的大跳空。如果你是那种"不太确定自己需要多少 AI 辅助"的开发者，Comate 的梯度设计让你很难选错档位。

### 3.6 MiniMax：一匹你没注意到的黑马

MiniMax 在 2026 年突然发力的 M3 模型，有 1M 上下文窗口，原生多模态能力，在 Coding 和 Agent 场景上的表现被多家评测机构标记为"异军突起"。

Token Plan 定价：Plus ¥49/月 → Max ¥119/月 → Ultra ¥469/月。桌面版免费下载，可以直接体验 M3 的编码能力。

**¥119/月的 Max 套餐是个人开发者的甜点档**：比智谱 Pro（¥149）便宜，比 Kimi Moderato（¥79）贵一些，但 M3 的实际编码表现如果真如宣传所说，这个价格有很高的性价比。

### 3.7 科大讯飞星火飞码：低调的实干家

讯飞的星火飞码（iFlyCode）是最低调的一家——官网上甚至没有独立的编程助手定价页。但实际产品是存在的：免费版提供基础编程辅助，个人版 ¥69/月（特价 ¥3.9/月起），支持 VS Code 和 JetBrains IDE。

团队版 ¥129/人/月，支持多账号管理和私有化部署，这在 7 家里是相对少见的定价模式——按人头收费而非按额度收费。

**适合谁**：如果你的团队已经在用讯飞的其他 AI 产品（语音、翻译等），星火飞码是自然延伸。但如果只看 Coding 单项，讯飞在模型知名度上还需要时间追赶。

### 3.8 & 3.9 商汤和零一万物：缺席者的信号

**商汤 SenseNova**：没有独立的 Coding Plan，只有 API 按量计费（每 5 小时 1,500 次免费调用）。对于开发者来说，这意味着你需要自己动手把 SenseNova 的 API 接入到 IDE 里——不是不行，但门槛明显高于装个插件。

**零一万物 Yi**：已于 2026 年 8 月 3 日宣布停止新用户注册和充值，9 月 3 日起完全停止模型体验和 API 调用。转向企业级 AI 解决方案（老板 AI、投资官 AI、销冠 AI）。这是一个值得注意的信号——**在 Coding Plan 这个赛道，如果做不到前几名，退出可能是比硬撑更好的选择**。

## 四、性价比深度对比

光看价格是不够的。我们把几个关键维度拆出来单独比：

### 4.1 免费体验门槛

| 档位 | 产品 | 免费额度 |
|------|------|---------|
| 🥇 最慷慨 | Trae | 500积分/月，全功能可用 |
| 🥈 次慷慨 | Qoder CN | 300 Credits/2周试用 |
| 🥉 有门槛 | Comate | 注册送¥10额度 |
| 不设免费 | Kimi Code | 最低¥39/月 |

如果你只是想试试 AI Coding 到底能不能帮你，**Trae 的免费版是最佳起点**——全功能、有积分、有云端任务，几乎零成本体验。

### 4.2 主力档（¥50-¥150）性价比

这个区间是个人开发者最纠结的地段：

| 产品 | 主力档 | 月费 | 额度 | 核心模型 | 性价比评级 |
|------|--------|------|------|---------|-----------|
| Trae | Pro | ¥59 | 4,000积分 | Doubao-Seed | ⭐⭐⭐⭐⭐ |
| Qoder CN | 专业版 | ¥59 | 2,000 Credits | Qwen3.8-Max | ⭐⭐⭐⭐ |
| Comate | 专业版 | ¥59 | 含¥55模型额度 | ERNIE | ⭐⭐⭐⭐ |
| Kimi Code | Moderato | ¥79 | 周更新额度 | K3 (1M ctx) | ⭐⭐⭐⭐ |
| MiniMax | Max | ¥119 | Token额度 | M3 (1M ctx) | ⭐⭐⭐ |
| 智谱 GLM | Pro | ¥149 | ~400 prompts/5h | GLM-5.3 | ⭐⭐⭐ |

**三家 ¥59 是核心战场**。Trae 积分最多，Qoder 产品矩阵最深，Comate 梯度最平滑。选哪家取决于你更看重什么：额度（Trae）、产品丰富度（Qoder）、还是升级灵活性（Comate）。

Kimi Code Moderato ¥79 和 MiniMax Max ¥119 虽然贵一些，但 K3 和 M3 的 1M 上下文窗口是 ¥59 档没有的能力。如果你经常需要 AI 理解整个项目上下文，这 ¥20-60 的差价可能花得最值。

### 4.3 旗舰档（¥400+）：重度用户的军备竞赛

这个价格已经是"工具成本"的上限了——¥469-629/月，相当于一笔中级 SaaS 订阅。但如果你每天的编码产出高度依赖 AI，这笔钱可能比雇一个 junior 开发者便宜得多。

旗舰档的核心竞争在以下三家：

- **Trae Ultra ¥629/月**：40,000 积分，新模型优先体验——字节的最大诚意。
- **Kimi Code Allegro ¥559/月**：K3 全能力解锁——月之暗面的王牌。
- **Qoder CN 旗舰版 ¥559/月**：20,000 Credits + Cloud Agents——团队场景的最优解。

## 五、选购建议：对号入座

### 场景一：我想免费试试 AI Coding

→ **Trae 免费版**。500 积分/月，全功能开放，没有任何隐藏门槛。用着不爽随时换。

### 场景二：我是个人开发者，轻度到中度使用

→ **Trae Pro（¥59/月）** 或 **Qoder CN 专业版（¥59/月）**。两者积分/Credits 都够日常使用。如果你用的 IDE 是 JetBrains 系列，优先 Qoder（原生支持更好）。如果你偏爱 VS Code，Trae 的体验打磨得更细。

### 场景三：我经常需要 AI 理解整个项目

→ **Kimi Code Moderato（¥79/月）** 或 **MiniMax Max（¥119/月）**。1M 上下文窗口在做大型代码库级别的任务时，体验提升非常明显。K3 vs M3 的选择取决于你对两个模型实际表现的偏好——建议先用桌面版 MiniMax Code 免费体验 M3，再决定。

### 场景四：我是团队负责人，要给团队配 AI 工具

→ **Qoder CN（旗舰版 ¥559/月 + Cloud Agents）** 或 **科大讯飞星火飞码（团队版 ¥129/人/月）**。Qoder 的云端 Agent 功能适合需要自动化任务的团队；讯飞按人头收费的模型更适合预算可控的固定团队。

### 场景五：预算不敏感，追求最强能力

→ **Trae Ultra（¥629/月）** 积分最多 + 新模型优先 + **Kimi Code Allegro（¥559/月）** K3 全能力 + **Qoder CN 旗舰版（¥559/月）** 产品最全。三者可以互补——很多重度用户实际上订阅了不止一个。

## 六、结语

2026 年 8 月的国内 AI Coding 市场，有几个值得记住的趋势：

1. **¥59 成了兵家必争之地**。三家巨头在这个点位上的竞争，意味着个人开发者只需要一顿火锅的钱，就能拿到足以覆盖日常工作的 AI 编码辅助。

2. **上下文窗口正在定义新的价格分层**。K3 和 M3 的 1M 上下文，让 ¥79-119 的区间有了一条"体验溢价"的护城河。如果你的工作流需要 AI 理解大型代码库，这个溢价非常合理。

3. **零一万物的退出是一个信号**。Coding Plan 这个赛道不是谁都能玩——它需要模型能力、IDE 集成、开发者社区三件事同时做好。2026 年下半年，看到更多整合和退出都不会奇怪。

4. **最好的策略可能是"混用"**。免费版 Trae 做日常补全，Kimi Code 在需要大上下文时上阵，Qoder 的 Cloud Agents 跑自动化任务——三家加起来的成本可能比单买一个旗舰套餐还低。

最后给一个实在的建议：**不要因为价格选工具，也不要因为名气选工具**。先用各自的免费版或低门槛方案跑一遍你自己的实际工作流，看哪个模型在你最常写的语言、最常做的任务上表现最好。毕竟，一个月 ¥59 还是 ¥79 的差别，远小于一个真正好用的 AI 助手每天帮你省下的那一个小时。Coding Plan 的价格是透明的，但好模型的边际收益，只有你自己的键盘知道。
